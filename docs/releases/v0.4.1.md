# mIDE 0.4.1 — Linux security update

This patch release hardens Go Live and backports a GLib safety fix. The downloadable build is a Linux x86-64 AppImage only; no Windows, macOS or ARM binaries are included.

## Security fixes

- Validate the HTTP Host against the local server address and active port; reject malformed and ambiguous requests.
- Block hidden project files and directories, including `.env` and `.git`, and symlink aliases to them. The root `.well-known` directory remains available.
- Reject control characters and encode redirect paths and directory links, preventing HTTP header injection and `javascript:` links from crafted filenames.
- Use nonblocking connections, request/response deadlines and connection limits so slow clients cannot block other requests or server shutdown.
- Bound served files to 16 MiB and directory listings to 2,048 entries; limit connections to 16, including at most 8 live-reload streams.
- Backport the upstream GLib `VariantStrIter` mutable-pointer fix for RUSTSEC-2024-0429 while retaining compatibility with the GTK3/Tauri stack. The local source patch has provenance checks and an optimization-enabled regression test.

## Notes

The remaining RustSec warning about the unmaintained build dependency `proc-macro-error` is tracked; this release does not claim a completely clean dependency audit. The GLib backport is maintained locally and checked separately because Cargo-audit skips local packages.

Linux desktop testing has been performed on Arch Linux / Omarchy. The release workflow builds the AppImage on Ubuntu 22.04; this is not a claim of manual testing on every Linux distribution. Node.js 22.12+ on PATH is required for Format Document.

Download the AppImage, allow execution and launch it. `SHA256SUMS` is provided for download-integrity verification. It is not a signature proving publisher identity.
