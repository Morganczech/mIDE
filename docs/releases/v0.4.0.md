## mIDE 0.4.0

A minimal editor for learning web programming by writing code manually, without autocomplete or AI.

### Changes

- Move files and folders by dragging in Explorer, with a visible drag preview. Import external files by dropping them into the project.
- Copy relative or absolute paths and move items using the keyboard-accessible Move to… dialog. Open tabs and unsaved edits follow moves.
- Read-only image tabs, image metadata, source-path hover previews and small gutter thumbnails, including icons.
- Offline HTML and CSS hover documentation with direct MDN links and independent settings.
- Searchable offline troubleshooting guides in Sources.
- Recently opened projects on the start page.
- Auto Save when leaving the editor or switching apps, enabled by default and configurable in Settings.
- Ctrl+Alt+S opens or closes Sources.

### Download and run

Download the `.AppImage` asset below for **Linux x86_64 (Intel/AMD)**. Allow execution in your file manager's properties, then open it. No system installation is required.

From a terminal in the download directory:

```sh
chmod +x ./mIDE_*.AppImage
./mIDE_*.AppImage
```

`SHA256SUMS` contains the download's SHA-256 checksum. With both files in the same directory, verify using `sha256sum -c SHA256SUMS`.

### Compatibility and known requirements

- **Manual testing has been performed only on Arch Linux / Omarchy.** Other Linux distributions have not been manually verified. No Windows or macOS downloads are provided.
- The AppImage is built on Ubuntu 22.04 for a broader compatibility baseline; this does not establish that every distribution is supported.
- Some systems need FUSE support. See the [AppImage troubleshooting guide](https://docs.appimage.org/user-guide/troubleshooting/fuse.html).
- **Format Document requires Node.js 22.12+ on the application's PATH** (Node 24 LTS recommended). Node.js is not bundled. Editing and the integrated terminal do not require it.
- Auto Save writes changed open files when focus leaves the editor. Disable it under **Settings → Saving** if you prefer explicit saves.
