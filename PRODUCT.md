# mIDE

A quiet desktop editor for learning web programming by writing code manually.

## Platform
Tauri 2 desktop application for Linux, macOS and Windows. Linux / Arch / Omarchy is the primary development platform.

## Stack
Rust, React, TypeScript, Vite, CodeMirror 6 and ordinary CSS. One window and one project, no global state framework.

## Product constraints
Only Explorer, file tabs, editor, status bar and an optional hidden terminal. No AI, completion, LSP, diagnostics, debugger, Git UI, extensions, embedded documentation viewer, telemetry, accounts or cloud features. Syntax highlighting and explicit formatting do not suggest code. No automatically inserted brackets or tags. No autosave.

## Initial defaults
Name: mIDE. English UI. Dark theme. System fonts. Native window decorations. No session restore. Focus on comfortable manual editing with keyboard access.

## Sources

Sources is a global, offline-browsable library of web development links, available without a project. It opens external resources in the system browser. A bundled JSON catalog covers supported technologies, learning materials, tools, colors, fonts, icons, photos and inspiration. Users can add and edit personal links, hide or restore built-ins, save favorites, and import/export a versioned JSON collection through native dialogs. Personal data is stored locally; no accounts, synchronization or remote previews.
